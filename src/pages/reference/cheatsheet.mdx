## Mini-notation

| Symbol | Meaning |
| --- | --- |
| space | sequence (all squeezed into one cycle) |
| `~` `-` | rest |
| `[ ]` | subdivide one slot |
| `< >` | one element per cycle (`<a b>` = `[a b]/2`) |
| `*n` `/n` | faster / slower |
| `@n` `_` | longer |
| `!n` | repeat without speeding up |
| `,` | parallel layers |
| `?` `?p` | randomly drop (50%, or probability p) |
| `\|` | pick one at random |
| `(p,s,r)` | euclidean: p pulses, s steps, r rotation |
| `{a, b}%n` | polymeter at n steps per cycle |
| `:n` | sample index |
| `name:i:g` | sample, index, gain |
| `..` | range, e.g. `"0 .. 7"` |
| `^` | mark the step level for stepwise functions |

## Sources

| Function | Purpose |
| --- | --- |
| `s()` / `sound()` | sample or synth name |
| `bank()` | drum machine prefix |
| `n()` | sample index / scale degree / voice index |
| `note()` | pitch by name or MIDI number |
| `freq()` | pitch in Hz |
| `samples()` | load a sample map |
| `soundAlias()` | alias an existing sound |

Synth sources: `sine` `triangle` `square` `sawtooth` `supersaw` `pulse` `user` · noise:
`white` `pink` `brown` `crackle` · wavetables: `wt_*` · ZZFX: `z_*` · General MIDI: `gm_*`
