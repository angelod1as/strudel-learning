## note()

`note()` accepts note names or MIDI numbers, interchangeably.

<Strudel code={`note("c e g b").s("piano")`} label="letters" />

<Strudel code={`note("48 52 55 59").s("piano")`} label="midi numbers — same notes" />

A note name is a letter `a`–`g`, optional accidentals (`b` flat, `#` sharp), optional octave.
Octave defaults to **3**.

<Strudel code={`note("c2 e3 g4 b5").s("piano")`} label="octaves" />

<Strudel code={`note("db eb gb ab bb").s("piano")`} label="flats" />

<Box>
MIDI 60 is middle C (`c5` in Strudel's numbering is not 60 — `note("60")` and `note("c4")` are the
same pitch). When in doubt, use numbers: they are unambiguous, and they can be added to.
</Box>

Decimals work too, which gets you microtonality for free:

<Strudel code={`note("60 60.5 61 61.5").s("sawtooth")`} label="quarter tones" />

## note vs sound

`note` sets pitch, `s` sets timbre. They are independent and combine:

<Strudel code={`note("48 67 63 [62, 58]").s("piano, gm_electric_guitar_muted")`} label="two instruments, same notes" />

If you set `note` but no `s`, the default sound is `triangle`.

## n() + scale()

Remembering which notes are in a key is work. `scale()` does it for you: `n` becomes a **scale
degree**, zero-indexed, and every number sounds right.

<Strudel code={`n("0 2 4 <[6,8] [7,9]>").scale("C:minor").s("piano")`} />

<Box kind="try">
Type any numbers at all into that `n`. Negative numbers go below the root. Because the scale filters
the result, you cannot play a wrong note — which is exactly why this is the fastest way to sketch
a melody.
</Box>

The scale name is `root:type`, with the root defaulting to octave 3:

| Example | |
| --- | --- |
| `"C:major"` `"A2:minor"` | the usual suspects |
| `"D:dorian"` `"G:mixolydian"` | modes |
| `"A2:minor:pentatonic"` | multi-word scale names joined by `:` |
| `"C:ritusen"` `"C:major:blues"` | anything [tonaljs](https://github.com/tonaljs/tonal) knows |

Because the argument is a pattern, the key can move:

<Strudel
  code={`setcpm(60)
n("<0 -3>, 2 4 <[6,8] [7,9]>")
  .scale("<C:major D:mixolydian>/4")
  .s("piano")`}
  label="modulating between two scales"
/>

<Box kind="warn">
Scale names must not contain spaces inside double quotes — `"C major"` would be read as a
*sequence of two things*. Use `"C:major"`, or single quotes: `'C major'`.
</Box>

## Transposing

`add()` shifts numbers. On a `note` pattern it adds semitones; on an `n` pattern inside a scale it
adds **scale degrees**, which keeps you in key:

<Strudel code={`note("c3 e3 g3".add("<0 5 7 0>")).s("piano")`} label="add: chromatic semitones" />

<Strudel code={`n("0 2 4 6".add("<0 3 4 0>")).scale("C:major").s("piano")`} label="add inside a scale: diatonic" />

Stacking a chord is just adding several things at once:

<Strudel code={`n("0 [2 4] <3 5> [~ <4 1>]".add("<0 [0,2,4]>")).scale("C5:minor").s("gm_xylophone").room(.5)`} />

Two more precise tools from the tonal package:

<Strudel code={`"[c2 c3]*4".transpose("<0 -2 5 3>").note()`} label="transpose: semitones or interval names like 3M, 5P" />

<Strudel
  code={`"[-8 [2,4,6]]*2"
  .scale('C4:bebop:major')
  .scaleTranspose("<0 -1 -2 -3 -4 -5 -6 -4>*2")
  .note()`}
  label="scaleTranspose: move by scale steps, staying in key"
/>

## Chords and voicings

Writing chord symbols and letting Strudel choose the notes:

<Strudel code={`chord("<C Am F G>").voicing().s("piano")`} label="chord symbols → actual notes" />

`voicing()` picks a sensible inversion so the chords do not leap around. You can steer it:

| Control | Effect |
| --- | --- |
| `dict('ireal')` | use a jazz voicing dictionary |
| `anchor("c5")` | the reference note to align to |
| `mode("below")` | top note at or under the anchor |
| `mode("above")` | bottom note at or above the anchor |
| `mode("root:g2")` | bottom note is the chord root, above g2 |
| `offset(1)` | shift to the next voicing up |
| `n("0 1 2")` | play the voicing like a scale — an arpeggio |

<Strudel
  code={`n("0 1 2 3").chord("<C Am F G>").mode("above:c3").voicing()
  .s("gm_electric_guitar_clean").clip(2)`}
  label="arpeggiating a voicing with n"
/>

A full backing track — chords plus a bassline from the same source pattern:

<Strudel
  code={`"<C^7 A7b13 Dm7 G7>*2".layer(
  x => x.voicing().struct("[~ x]*2").note().s("gm_electric_piano_1").room(.4),
  x => x.rootNotes(2).note().s("sawtooth").lpf(800).decay(.2).sustain(0)
)`}
  label="layer: same chords, two treatments"
/>

`rootNotes(octave)` turns chord symbols into their root note — the bass player's job.

## Arpeggios

Four different ways to do the same thing, each suggesting different music:

<Strudel code={`note("c eb g c4").clip(2).s("gm_electric_guitar_clean")`} label="by hand" />

<Strudel code={`n("0 2 4 7").scale("C:minor").clip(2).s("gm_electric_guitar_clean")`} label="by scale degree" />

<Strudel
  code={`note("<[c,eb,g]!2 [c,f,ab] [d,f,ab]>").arp("0 [0,2] 1 [0,2]").s("piano")`}
  label="arp(): pick indices out of a stacked chord"
/>

<Strudel
  code={`"0".off(1/3, add(2)).off(1/2, add(4))
  .n().scale("C:minor").s("gm_electric_guitar_clean")`}
  label="off(): echo the note at an interval — an arpeggio made of delays"
/>

<QA q="When should I use note, n+scale, or chord+voicing?">
`note` when you know exactly which pitches you want. `n`+`scale` when you want to improvise shapes
and stay in key — it is the best choice while sketching. `chord`+`voicing` when you are thinking
harmonically (a progression) rather than melodically, or when you want a bassline and a comp that
agree with each other automatically.
</QA>

## Recap

| Function | Purpose |
| --- | --- |
| `note()` | pitch by name or MIDI number |
| `n()` + `scale()` | pitch by scale degree |
| `add()` | transpose (semitones, or degrees inside a scale) |
| `transpose()` | semitones or interval names |
| `scaleTranspose()` | move by scale steps |
| `chord()` + `voicing()` | chord symbols to notes |
| `rootNotes(oct)` | chord symbols to bass notes |
| `arp()` | play a stacked chord one index at a time |
