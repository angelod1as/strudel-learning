An oscillator running below hearing range — typically 0.1 to 20 Hz. You do not hear the wave
itself; you hear what it does to something else. Point it at a filter cutoff and you get a wah or
a wobble; at gain, tremolo or a pulsing gate; at pitch, vibrato; at pan, the sound circling you.

Strudel has two levels of modulation, and picking the right one matters:

| | <L to="/tutorial/signals">Signals</L> | `lfo()` |
| --- | --- | --- |
| Level | pattern | audio |
| Sampled | once per event | continuously |
| Works on a held note | no | yes |
| Can modulate | anything, incl. notes and structure | audio controls of a voice |

<Box kind="try">
Every patch below is one held note or one repeated sound, on purpose: with a single event per bar,
anything you hear moving is the LFO. Add `._spectrum({height: 300, width: 800})` on its own line to
*watch* the filter move, and `._scope()` to watch the waveform. Both draw; neither makes sound, and
neither is part of any answer.
</Box>

## The positional rule

`.lfo()` with no arguments modulates **whatever control came immediately before it**. Six
characters, and where you put them is the whole instruction.

## The config object

Everything except the `id` lives in a single `{ key: value }` object. Every key has a short alias,
and every value can itself be a pattern.

| Key | Alias | Meaning |
| --- | --- | --- |
| `control` | `c` | which parameter to modulate |
| `rate` | `r` | speed in Hz |
| `sync` | `s` | speed in times per cycle (tempo-locked) |
| `depth` | `dep`, `dr` | modulation depth, **relative** to the value |
| `depthabs` | `da` | total modulation swing, in absolute units |
| `dcoffset` | `dc` | shifts the centre of the modulation |
| `shape` | `sh` | waveform |
| `skew` | `sk` | asymmetry of triangle / pulse width of square |
| `curve` | `cu` | exponent applied to the wave |
| `retrig` | `rt` | > 0.5 restarts the LFO on every event |
| `subControl` | `sc` | when modulating another LFO, which of its parameters |
| `fxi` | — | index into an `FX()` chain |

### rate vs sync

`rate` is in hertz — absolute speed, ignoring the tempo. `sync` is in cycles — tempo-locked.

### dcoffset — which way it moves

By default the wave is centred on the value, going equally above and below. `dcoffset` slides that
window. The default is `-0.5`.

<Exercise id="lfo/dcoffset" title="Up only, down only, both"
  goal="Move the modulation window so the LFO can only raise a value, or only lower it."

  <Step check={{ includes: 'dcoffset', fn: "(h) => { const e = h.find(x => x.value.lfo); const m = e && e.value.lfo['0']; return (m && m.dcoffset === -0.5) || 'Expected dcoffset -0.5.' }" }}
        solution={`s("saw").lpf(600).lfo({ c: 'lpf', r: 2, da: 200, dcoffset: -0.5 })`}>
    Add `dcoffset: -0.5`. Nothing changes — you have written out the default. The cutoff swings
    500 to 700, centred on 600.
  </Step>
  <Step check={{ fn: "(h) => { const e = h.find(x => x.value.lfo); const m = e && e.value.lfo['0']; return (m && m.dcoffset === 0) || 'Expected dcoffset 0.' }" }}
        hints={['Think of it as sliding the whole wave up until its bottom sits on the value.']}

    Change it to `0`. Now the modulation only ever **raises** the value: 600 to 800, never below.
    The sound has a floor it always returns to.
  </Step>
  <Step check={{ fn: "(h) => { const e = h.find(x => x.value.lfo); const m = e && e.value.lfo['0']; return (m && m.dcoffset === -1) || 'Expected dcoffset -1.' }" }}

        solution={`s("saw").lpf(600).lfo({ c: 'lpf', r: 2, da: 200, dc: "<-0.5 -1 0>" })`}>
    Use the alias and cycle through all three: `dc: "<-0.5 -1 0>"`. Centred, downward only, upward
    only — three bars, and you can hear the difference without looking at anything.
  </Step>

    Add `.lfo({ sync: 2, depthabs: 400, sh: 'sine' })` after `.lpq(8)`. That is not a wobble — it
    is a thin flutter. The positional rule struck: the control immediately before `.lfo()` is
    `lpq`, so you just swung the *resonance* by 400.
  </Step>
  <Step check={{ includes: "c: 'lpf'", fn: "(h) => { const e = h.find(x => x.value.lfo); const m = e && e.value.lfo['0']; return (m && m.control === 'cutoff' && m.depthabs === 400) || 'Expected the LFO on the cutoff with depthabs 400.' }" }}

    Add `c: 'lpf'` to the front of the object. There it is: the cutoff swings 300 to 700 twice a

  </Step>
  <Step check={{ includes: '<1 2 4>', cycles: 3, fn: "(h) => { const y = i => { const e = h.find(x => Math.floor(x.t + 1e-9) === i && x.value.lfo); return e && e.value.lfo['0'].sync; }; return ([0, 1, 2].map(y).join(',') === '1,2,4') || 'Expected one, then two, then four wobbles per bar.' }" }}

  </Step>

    Add `.room(.3)` on the end. `room` is reverb, and the number is how much of it. Reverb after

  </Step>

### Hard gate

### Vibrato, the one that is already built for you

<Exercise id="lfo/vibrato" title="vib: a pitch LFO with no config object"
  goal="Use the dedicated pitch modulator and set its depth in semitones."
  start={`note("a e")
  .s("sawtooth")`}
  target={`note("a e")
  .s("sawtooth")
  .vib("<.5 1 2 4 8 16>:12")`}>
  <Step check={{ includes: '.vib(', has: { vib: 4 } }}
        solution={`note("a e")
  .s("sawtooth")
  .vib(4)`}>
    Add `.vib(4)`: four wobbles a second on the pitch. No control name, no depth, no shape — this
    is a fixed-purpose modulator and it only does one thing.
  </Step>
  <Step check={{ fn: "(h) => h.every(e => e.value.vib === 4 && e.value.vibmod === 12) || 'Expected a vibrato of 4 with a depth of 12 semitones.'" }}

        solution={`note("a e")
  .s("sawtooth")
  .vib("4:12")`}>
    Set the depth too: `.vib("4:12")`. The colon separates rate from depth **in semitones**, so
    that is a full octave of wobble — a siren, not a violin. Try `"4:0.3"` for something you would
    actually keep.
  </Step>
  <Step check={{ includes: '<.5 1 2 4 8 16>', cycles: 6, fn: "(h) => { const v = i => { const e = h.find(x => Math.floor(x.t + 1e-9) === i); return e && e.value.vib; }; return ([0, 1, 2, 3, 4, 5].map(v).join(',') === '0.5,1,2,4,8,16') || 'Expected the rate to double every bar from 0.5 to 16.' }" }}
        solution={`note("a e")
  .s("sawtooth")
  .vib("<.5 1 2 4 8 16>:12")`}>
    Pattern the rate: `.vib("<.5 1 2 4 8 16>:12")`. Six bars, doubling each time. Somewhere in the

    and an oscillator, and you can hear exactly where it is. Add `._scope()` to watch it.
  </Step>

<QA q="lfo(), vib(), tremolo() and phaser() all modulate things. What is the difference?">
`vib`, `tremolo` and `phaser` are fixed-purpose modulators wired to pitch, amplitude and a phaser
bank respectively — fewer controls, instantly musical. `lfo()` is the general mechanism: any
control, any shape, any depth, and it can modulate other modulators. Reach for the specific ones
first; reach for `lfo()` when they do not go where you want.
</QA>

## Recap

| Thing | Purpose |
| --- | --- |
| `.lfo()` | modulate the control immediately before it |
| `{c: 'name'}` | choose the target explicitly |
| `{r: hz}` / `{s: perCycle}` | speed, free or tempo-synced |
| `{depth}` / `{depthabs}` | relative, or the total swing in real units |
| `{dc: 0 / -1}` | only raise / only lower |
| `{sh, sk, cu}` | shape, skew, curve |
| `{retrig: 1}` | restart the wave on every event |
| `.lfo({...}, 'name')` | name it so you can modify it later |
| `{sc: 'param'}` | modulate a parameter of another LFO |
| `{fxi: n}` | target the nth effect in an `FX()` chain |
| `vib`, `tremolo`, `phaser` | fixed-purpose modulators, no config needed |
