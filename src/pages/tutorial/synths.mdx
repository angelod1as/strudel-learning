Every sound in this chapter is generated on the spot, with no audio file behind it. You will build
each one by typing: a step asks for one change, you press ctrl+enter, and you listen to what moved.

<Box kind="try">
Chain `._scope()` onto any pattern to watch its waveform, or `._spectrum()` to watch its harmonics.
They draw into the page and change nothing about the sound, so leave them on while you work — half
of what follows is easier to see than to describe.
</Box>

## The basic waveforms

Four oscillators, in order of how much they contain: `sine` has the fundamental and nothing else,
`triangle` and `square` have the odd harmonics (weak, then strong), `sawtooth` has all of them.

<Exercise id="synths/waveforms" title="Hear all four"
  goal="Take one bass line through every basic oscillator, then through the short aliases."
  start={`note("c2 eb2 g2 c3")`}
  target={`note("c2 eb2 g2 c3").s("<saw sqr tri sin>")`}>
  <Step check={{ includes: '.s(', has: { s: 'sawtooth' } }}
        hints={['`.s()` picks the sound source, the same function you use for drum samples.']}
        solution={`note("c2 eb2 g2 c3").s("sawtooth")`}>
    Play it first: with `note` and no `s`, you are hearing the default, `triangle`. Now add
    `.s("sawtooth")`. Every harmonic is present, so it buzzes — this is the classic synth bass.
  </Step>
  <Step check={{ has: { s: 'square' } }}
        solution={`note("c2 eb2 g2 c3").s("square")`}>
    Change it to `.s("square")`. Only odd harmonics, all of them strong: hollow and reedy, a
    clarinet or a Game Boy.
  </Step>
  <Step check={{ has: { s: 'sine' } }}
        solution={`note("c2 eb2 g2 c3").s("sine")`}>
    Change it to `.s("sine")`. Nothing but the fundamental. Down here it is a sub bass, and it
    almost disappears on laptop speakers.
  </Step>
  <Step check={{ includes: '<', cycles: 4, match: { keys: ['s'] } }}
        target={`note("c2 eb2 g2 c3").s("<sawtooth square triangle sine>")`}
        hints={['`< >` plays one element per cycle, and `s` takes mini-notation like any other argument.']}
        solution={`note("c2 eb2 g2 c3").s("<sawtooth square triangle sine>")`}>
    Put all four in one string, one per bar: `.s("<sawtooth square triangle sine>")`. Four bars,
    four timbres, same notes.
  </Step>
  <Step check={{ includes: 'saw sqr', cycles: 4, match: { keys: ['s', 'note'] } }}
        target={`note("c2 eb2 g2 c3").s("<saw sqr triangle sine>")`}
        hints={['Each name shortens to its first syllable.']}
        solution={`note("c2 eb2 g2 c3").s("<saw sqr triangle sine>")`}>
    Every name has a short alias. Change `sawtooth` to `saw` and `square` to `sqr`: bars 1 and 2
    are identical, with less typing.
  </Step>
  <Step check={{ includes: 'tri sin>', cycles: 4, match: { keys: ['s', 'note'] } }}
        hints={['Same rule: the first syllable.']}
        solution={`note("c2 eb2 g2 c3").s("<saw sqr tri sin>")`}>
    Shorten the other two: `triangle` to `tri`, `sine` to `sin`. Still the same four bars.
  </Step>
</Exercise>

| Wave | Harmonics | Sounds like |
| --- | --- | --- |
| `sine` | fundamental only | pure, flute-ish, sub bass |
| `triangle` | odd, weak | soft, hollow |
| `square` | odd, strong | reedy, chiptune |
| `sawtooth` | all | bright, buzzy — the classic synth bass/lead |

If you set `note` but no `s`, the default is `triangle`. Besides the four, the engine also registers
`supersaw`, `pulse`, `sbd` and `bytebeat`.

  target={`note("c2*8").s("<square sine>")`}
  check={{ cycles: 2, match: { keys: ['s', 'note'] } }}
  hints={[
    'Eight eighth notes in one bar is `"c2*8"`, which you already have.',

    'One element per cycle is what `< >` does.',
  ]} />

## Fat oscillators: supersaw and pulse

`supersaw` is not one saw but a stack of them, each detuned a little and spread across the stereo
field — the Roland JP-8000 sound under most trance leads. Ableton's Unison device does the same job.

<Exercise id="synths/supersaw" title="Stack and detune"
  goal="Turn one saw into a wall of saws, and control how wide it gets."
  start={`note("<c2 eb2 g1 bb1>").s("sawtooth")`}
  target={`note("<c2 eb2 g1 bb1>").s("supersaw").unison("<1 3 7>").detune(.2).spread(.8)`}>
  <Step check={{ has: { s: 'supersaw' } }}
        solution={`note("<c2 eb2 g1 bb1>").s("supersaw")`}>
    Change `sawtooth` to `supersaw`. Already thicker, and slightly restless: the voices are
    beating against each other.
  </Step>
  <Step check={{ includes: '.unison(', has: { unison: [2, 16] } }}
        hints={['`unison` counts voices, not semitones.']}
        solution={`note("<c2 eb2 g1 bb1>").s("supersaw").unison(7)`}>
    Add `.unison(7)`: seven saws instead of the default. More voices, more movement.
  </Step>
  <Step check={{ includes: '.detune(', has: { detune: [0.05, 1] } }}
        hints={['Small values are a chorus; whole numbers start to sound like separate notes.']}
        solution={`note("<c2 eb2 g1 bb1>").s("supersaw").unison(7).detune(.2)`}>
    Add `.detune(.2)`: how far apart the seven are tuned. Try `2` and then `24.1` before you move
    on — at `24.1` it stops being one note and becomes a chord.
  </Step>
  <Step check={{ has: { spread: [0.5, 1] } }}
        hints={['`spread` runs from 0 (all voices centred) to 1 (hard left to hard right).']}
        solution={`note("<c2 eb2 g1 bb1>").s("supersaw").unison(7).detune(.2).spread(.8)`}>
    Add `.spread(.8)`. The voices fan out across the stereo image. Listen in headphones: the note
    stops coming from one point.
  </Step>
  <Step check={{ cycles: 3, match: { keys: ['unison'] } }}
        hints={['`unison` is an argument, so it takes mini-notation.']}
        solution={`note("<c2 eb2 g1 bb1>").s("supersaw").unison("<1 3 7>").detune(.2).spread(.8)`}>
    Make the width itself move: change `.unison(7)` to `.unison("<1 3 7>")`. One voice, three,
    seven — the bass line opens up over three bars.
  </Step>
</Exercise>

| Control | Effect on `supersaw` / `pulse` |
| --- | --- |
| `unison(n)` | how many stacked voices |
| `detune(x)` | how far apart they are tuned |
| `spread(0..1)` | how wide they sit in stereo |
| `pw(x)` | pulse width of the `pulse` oscillator |
| `pwrate` / `pwsweep` | LFO on the pulse width |

<Exercise id="synths/supersaw-challenge" title="Challenge: a trance lead"
  goal="`c4 eb4 g4 bb4` on a supersaw: 5 voices, detune .3, spread all the way out."
  start={`note("c4 eb4 g4 bb4")`}
  target={`note("c4 eb4 g4 bb4").s("supersaw").unison(5).detune(.3).spread(1)`}
  check={{ events: 4, has: { s: 'supersaw', unison: 5, detune: [0.2, 0.4], spread: [0.8, 1] } }}
  hints={[
    'Four controls in a chain: the source, the voice count, the detune amount, the stereo width.',
    '“All the way out” is the top of the `spread` range.',
  ]} />

A `pulse` is a square whose two halves are no longer equal. At a width of 0.5 it *is* a square; push
it towards 0 and it thins out into something nasal. Sweeping that width is the oldest trick in
subtractive synthesis, because a static pulse sounds dead and a moving one sounds alive.

<Exercise id="synths/pulse" title="Pulse width modulation"
  goal="Thin out a square by hand, then hand the job to an LFO."
  start={`note("d2*8")`}
  target={`note("d2*8")
  .s("pulse")
  .pw("<.1 .3 .5>")
  .pwrate(4)
  .pwsweep(.5)`}>
  <Step check={{ has: { s: 'pulse' } }}
        hints={['One control per line from here on, so each step is one line.']}
        solution={`note("d2*8")
  .s("pulse")`}>
    Play it first: the default `triangle`. Now add `.s("pulse")` on a new line. With no width set
    you are hearing something square-ish.
  </Step>
  <Step check={{ includes: '.pw(', has: { pw: [0.02, 0.2] } }}
        hints={['`pw` is the fraction of each period the wave spends high: 0.5 is a square.']}
        solution={`note("d2*8")
  .s("pulse")
  .pw(.1)`}>
    Add `.pw(.1)`. A tenth high, nine tenths low: thin, buzzy, and much quieter in the low end.
  </Step>
  <Step check={{ cycles: 3, match: { keys: ['pw'] } }}
        target={`note("d2*8")
  .s("pulse")
  .pw("<.1 .3 .5>")`}
        solution={`note("d2*8")
  .s("pulse")
  .pw("<.1 .3 .5>")`}>
    Change it to `.pw("<.1 .3 .5>")` and listen to the tone fill out over three bars.
  </Step>
  <Step check={{ has: { pwrate: [1, 20] } }}
        hints={['The rate is in Hz, like any LFO.']}
        solution={`note("d2*8")
  .s("pulse")
  .pw("<.1 .3 .5>")
  .pwrate(4)`}>
    Add `.pwrate(4)`: an LFO wobbling the width four times a second, around whatever `pw` you set.
  </Step>
  <Step check={{ has: { pwsweep: [0.1, 1] }, cycles: 3, match: { keys: ['note', 's', 'pw', 'pwrate', 'pwsweep'] } }}
        hints={['`pwsweep` is how far the LFO pushes the width, not how fast.']}
        solution={`note("d2*8")
  .s("pulse")
  .pw("<.1 .3 .5>")
  .pwrate(4)
  .pwsweep(.5)`}>
    Add `.pwsweep(.5)` for the depth of that wobble. This is the sound of a string machine, and
    the reason PWM pads never sit still.
  </Step>
</Exercise>

<Exercise id="synths/pulse-challenge" title="Challenge: a chiptune lead"
  goal="`a4 c5 e5 c5` on a pulse: width .25, wobbled at 6 Hz with depth .4."
  start={`note("a4 c5 e5 c5")`}
  target={`note("a4 c5 e5 c5").s("pulse").pw(.25).pwrate(6).pwsweep(.4)`}
  check={{ events: 4, has: { s: 'pulse', pw: [0.15, 0.35], pwrate: [5, 7], pwsweep: [0.3, 0.5] } }}
  hints={[
    'Three controls shape a pulse: the width itself, the speed of the LFO on it, and its depth.',
    '“Wobbled at 6 Hz” is a rate; “depth .4” is a sweep.',
  ]} />

## Noise

Noise has no pitch, only a colour: `white` is flat and hissy, `pink` rolls the top off, `brown`
rolls off twice as hard and sounds like distant surf.

<Exercise id="synths/noise" title="Three colours, then grit"
  goal="Compare the three noise sources, mix noise into a pitched tone, and thin it into crackle."
  start={`$: s("white*4")
_$: note("c3*4").s("sine")
_$: s("crackle*4").density(.2)`}
  target={`_$: s("<white pink brown>*4")
_$: note("c3*4").s("sine").noise("<0 .1 .5>")
$: s("crackle*4").density("<.01 .1 1>")`}>
  <Step check={{ cycles: 3, match: { keys: ['s'] } }}
        target={`$: s("<white pink brown>*4")
_$: note("c3*4").s("sine")
_$: s("crackle*4").density(.2)`}
        hints={['`< >` inside the quotes, `*4` outside it.']}
        solution={`$: s("<white pink brown>*4")
_$: note("c3*4").s("sine")
_$: s("crackle*4").density(.2)`}>
    Three lanes, and only the first one plays. In it, change `s("white*4")` to
    `s("<white pink brown>*4")`. Three bars: hard, medium, soft. The difference is how fast the
    energy falls off as the frequency rises.
  </Step>
  <Step check={{ has: { s: 'sine' } }}
        hints={['`_$:` mutes a lane and `$:` plays it. Nothing else on either line changes.']}
        solution={`_$: s("<white pink brown>*4")
$: note("c3*4").s("sine")
_$: s("crackle*4").density(.2)`}>
    Swap which lane plays: change the first lane's `$:` to `_$:` and the second lane's `_$:` to
    `$:`. A plain sine, with no noise in it yet.
  </Step>
  <Step check={{ includes: '.noise(', has: { s: 'sine', noise: [0.05, 1] } }}
        hints={['This is the `noise` *control*, not the `noise` sound source.']}
        solution={`_$: s("<white pink brown>*4")
$: note("c3*4").s("sine").noise(.3)
_$: s("crackle*4").density(.2)`}>
    Noise is also something you mix **into** an oscillator. Add `.noise(.3)` to the sine lane: a
    clean sine with breath on it.
  </Step>
  <Step check={{ cycles: 3, match: { keys: ['noise'] } }}
        target={`_$: s("<white pink brown>*4")
$: note("c3*4").s("sine").noise("<0 .1 .5>")
_$: s("crackle*4").density(.2)`}
        solution={`_$: s("<white pink brown>*4")
$: note("c3*4").s("sine").noise("<0 .1 .5>")
_$: s("crackle*4").density(.2)`}>
    Change it to `.noise("<0 .1 .5>")`. Bar 1 is pure, bar 2 is a flute, bar 3 is a broken speaker.
  </Step>
  <Step check={{ has: { s: 'crackle', density: [0.01, 2] } }}
        hints={['Same swap as before, one lane further down.', '`crackle` is its own sound source, and `density` is how many clicks per second.']}
        solution={`_$: s("<white pink brown>*4")
_$: note("c3*4").s("sine").noise("<0 .1 .5>")
$: s("crackle*4").density(.2)`}>
    Now the opposite of a wall of noise: mute the sine lane and play the third one,
    `s("crackle*4").density(.2)`. Individual clicks, vinyl-style.
  </Step>
  <Step check={{ cycles: 3, match: { keys: ['s', 'density'] } }}
        solution={`_$: s("<white pink brown>*4")
_$: note("c3*4").s("sine").noise("<0 .1 .5>")
$: s("crackle*4").density("<.01 .1 1>")`}>
    Change it to `.density("<.01 .1 1>")`. From an occasional tick to a downpour.
  </Step>
</Exercise>

## Vibrato

A pitch LFO, built in. `vib` is the rate in Hz and `vibmod` the depth in semitones — or write both
in one string, `"rate:depth"`.

<Exercise id="synths/vibrato" title="Wobble the pitch"
  goal="Go from a gentle singer's vibrato to a siren, write it in one string, then push the rate past a wobble."
  start={`note("<a4 e4>")
  .s("triangle")`}
  target={`note("<a4 e4>")
  .s("triangle")
  .vib("<.5 2 8 16>:2")`}>
  <Step check={{ includes: '.vib(', has: { vib: [1, 10] } }}
        hints={['The number is a rate in Hz — around 5 is what a singer does.']}
        solution={`note("<a4 e4>")
  .s("triangle")
  .vib(4)`}>
    Add `.vib(4)` on a new line: the pitch wobbles four times a second. That is expression.
  </Step>
  <Step check={{ includes: '.vibmod(', has: { vibmod: [0.1, 12] } }}
        hints={['Depth is in semitones, so `1` is a semitone either side.']}
        solution={`note("<a4 e4>")
  .s("triangle")
  .vib(4)
  .vibmod(2)`}>
    Add `.vibmod(2)`: two semitones of depth. Rate without depth is nothing; this is the knob that
    decides between "tasteful" and "seasick".
  </Step>
  <Step check={{ includes: ':', excludes: '.vibmod(', has: { vib: 4, vibmod: 2 } }}
        hints={['One string, one colon, no `vibmod` call left.']}
        solution={`note("<a4 e4>")
  .s("triangle")
  .vib("4:2")`}>
    Replace both lines with `.vib("4:2")`: rate, then depth, in one string. Nothing changes — it
    sets exactly the same two values.
  </Step>
  <Step check={{ has: { vib: 6, vibmod: 12 } }}
        hints={['Only the two numbers inside the string change.']}
        solution={`note("<a4 e4>")
  .s("triangle")
  .vib("6:12")`}>
    Change it to `.vib("6:12")`. Twelve semitones is an octave each way: an air-raid siren.
  </Step>
  <Step check={{ cycles: 4, match: { keys: ['vib', 'vibmod'] } }}
        hints={['The rate half of the string takes mini-notation: `< >` before the colon.']}
        solution={`note("<a4 e4>")
  .s("triangle")
  .vib("<.5 2 8 16>:2")`}>
    Now sweep the rate and pull the depth back to 2: `.vib("<.5 2 8 16>:2")`, one rate per bar.
    Past about 10 Hz you stop hearing a wobble and start hearing a new timbre — which is the whole
    idea behind FM, two sections down.
  </Step>
</Exercise>

<Exercise id="synths/vibrato-challenge" title="Challenge: siren"
  goal="One held `a4` per bar on a sawtooth, vibrato at 2 Hz and 12 semitones deep, written in the one-string form."
  start={`note("a4").s("sawtooth")`}
  target={`note("a4").s("sawtooth").vib("2:12")`}

## FM synthesis

Modulate the frequency of one oscillator with another, fast enough and you stop hearing a wobble and
start hearing a new harmonic spectrum. Two numbers do almost all of it: **how much** (`fm`, the
modulation index) and **what ratio** the modulator runs at (`fmh`, harmonicity). This is a DX7 in
two function calls.

<Exercise id="synths/fm" title="Index and harmonicity"
  goal="Take a sine from pure to metallic with `fm`, then change its character with `fmh`."
  start={`note("c3 e3 g3 b3").s("sine")`}
  target={`note("c3 e3 g3 b3").s("sine").fm("<0 1 4 12>").fmh("<1 2 3 1.41>")`}>
  <Step check={{ includes: '.fm(', has: { fm: [1, 20] } }}
        hints={['`fm` is the modulation index: 0 is off, and it has no upper limit worth respecting.']}
        solution={`note("c3 e3 g3 b3").s("sine").fm(4)`}>
    Add `.fm(4)`. The sine grows a whole set of sidebands and turns into something hollow and
    reedy — nothing was filtered, the harmonics were *created*.
  </Step>
  <Step check={{ cycles: 4, match: { keys: ['fm'] } }}
        target={`note("c3 e3 g3 b3").s("sine").fm("<0 1 4 12>")`}
        solution={`note("c3 e3 g3 b3").s("sine").fm("<0 1 4 12>")`}>
    Change it to `.fm("<0 1 4 12>")`: off, a hint, obvious, aggressive. Index is the brightness
    knob of FM.
  </Step>
  <Step check={{ includes: '.fmh(', has: { fmh: [1.5, 4] } }}
        hints={['Harmonicity is a ratio against the note you are playing, not a frequency.']}
        solution={`note("c3 e3 g3 b3").s("sine").fm("<0 1 4 12>").fmh(2)`}>
    Add `.fmh(2)`: the modulator now runs an octave above the carrier. Still musical, because 2 is
    a whole number.
  </Step>
  <Step check={{ cycles: 4, match: { keys: ['fm', 'fmh'] } }}
        hints={['Whole numbers land on harmonics; anything in between lands between them.']}
        solution={`note("c3 e3 g3 b3").s("sine").fm("<0 1 4 12>").fmh("<1 2 3 1.41>")`}>
    Change it to `.fmh("<1 2 3 1.41>")`. The first three bars stay in tune with themselves. The
    fourth, on a decimal, goes inharmonic: bells, gongs, metal.
  </Step>
</Exercise>

| Control | Meaning |
| --- | --- |
| `fm(i)` | modulation index — how much. 0 is off, high is metallic |
| `fmh(ratio)` | harmonicity: the modulator's frequency relative to the note |
| `fmattack` `fmdecay` `fmsustain` `fmrelease` | envelope on the modulation amount |
| `fmenv('lin'/'exp')` | envelope curve |

A fixed index is a static timbre. Real instruments are bright at the attack and mellow after it, and
that is what the FM envelope is for: it shapes the modulation amount over time, independently of
the volume envelope.

<Exercise id="synths/fm-envelope" title="Shape the modulation over time"
  goal="Move the metal to where it belongs: late, then early, then gone."
  start={`note("c3 e3 g3 b3").s("sine").fm(8).fmh(2)`}
  target={`note("c3 e3 g3 b3").s("sine").fm(8).fmh(2).fmdecay("<.05 .2 .8>").fmsustain(0).fmenv("<exp lin>")`}>
  <Step check={{ includes: '.fmattack(', has: { fmattack: [0.1, 1] } }}
        solution={`note("c3 e3 g3 b3").s("sine").fm(8).fmh(2).fmattack(.3)`}>
    Add `.fmattack(.3)`. Each note starts as a clean sine and the metal arrives 300 ms late — a
    bowed, swelling sound.
  </Step>
  <Step check={{ excludes: '.fmattack(', has: { fmdecay: [0.05, 1] } }}
        hints={['Delete the attack call and chain a decay instead.']}
        solution={`note("c3 e3 g3 b3").s("sine").fm(8).fmh(2).fmdecay(.2)`}>
    Replace `.fmattack(.3)` with `.fmdecay(.2)`. Almost nothing changes yet — a decay has nothing
    to fall *to* while the FM sustain level is still full.
  </Step>
  <Step check={{ includes: '.fmsustain(', has: { fmsustain: 0 } }}
        hints={['Sustain is a level, and you want it at the bottom.']}
        solution={`note("c3 e3 g3 b3").s("sine").fm(8).fmh(2).fmdecay(.2).fmsustain(0)`}>
    Add `.fmsustain(0)`. Now the decay bites: a metallic attack that drops to a plain sine. That
    single change is the difference between a buzz and an instrument.
  </Step>
  <Step check={{ cycles: 3, match: { keys: ['fmdecay'] } }}
        target={`note("c3 e3 g3 b3").s("sine").fm(8).fmh(2).fmdecay("<.05 .2 .8>").fmsustain(0)`}
        solution={`note("c3 e3 g3 b3").s("sine").fm(8).fmh(2).fmdecay("<.05 .2 .8>").fmsustain(0)`}>
    Change the decay to `"<.05 .2 .8>"`. Short is a mallet, medium is an electric piano, long is a
    bell still ringing.
  </Step>
  <Step check={{ includes: '.fmenv(', cycles: 6, match: { keys: ['fmdecay', 'fmenv'] } }}
        hints={['It takes `"exp"` or `"lin"`, and both fit in a `< >`.']}
        solution={`note("c3 e3 g3 b3").s("sine").fm(8).fmh(2).fmdecay("<.05 .2 .8>").fmsustain(0).fmenv("<exp lin>")`}>
    Add `.fmenv("<exp lin>")` to switch the curve every bar. Exponential dumps the brightness
    immediately and lingers; linear bleeds it away evenly. Percussion wants `exp`.
  </Step>
</Exercise>

<Box kind="try">
Two recipes to start from. **Bell:** `fmh` between 1.4 and 3.5 (decimals, deliberately), `fm` high,
`fmdecay` short, `fmsustain(0)`. **Electric piano:** `fmh(1)`, `fm(3)`, `fmdecay(.3)`,
`fmsustain(0)`, plus a short amplitude decay from <L to="/tutorial/envelopes">Envelopes</L>. The
difference between the two is almost entirely `fmh`.
</Box>

## Additive: partials and phases

Instead of carving harmonics away with a filter, state their amplitudes directly. `partials` takes
an array, one entry per harmonic; `phases` says where each harmonic starts in its cycle.

<Exercise id="synths/partials" title="Build a tone from harmonics"
  goal="Tame a saw with a partials array, then build a waveform from scratch and compute one."
  start={`note("c2 g2 c3 g2")
  .s("sawtooth")`}
  target={`note("c2 g2 c3 g2")
  .s("user")
  .partials(
    new Array(16).fill(0).map((_, i) => ((-1) ** (i + 1)) / (i + 1))
  )
  .phases(randL(16))`}>
  <Step check={{ includes: '.partials(', fn: "(h) => h.every((e) => Array.isArray(e.value.partials)) || 'Every note needs a partials array.'" }}
        hints={['One number per harmonic, starting at the fundamental.']}
        solution={`note("c2 g2 c3 g2")
  .s("sawtooth")
  .partials(
    [1, 1, 1, 0, 0, 0, 0, 0]
  )`}>
    Add `.partials([1, 1, 1, 0, 0, 0, 0, 0])`, with the array on a line of its own inside the
    call: it is what the next steps change. You have muted everything above the third harmonic:
    the saw loses its edge without a filter anywhere in sight.
  </Step>
  <Step check={{ has: { s: 'user' } }}
        hints={['The source is called `user`.']}
        solution={`note("c2 g2 c3 g2")
  .s("user")
  .partials(
    [1, 1, 1, 0, 0, 0, 0, 0]
  )`}>
    Change `.s("sawtooth")` to `.s("user")`. Now there is no starting waveform at all — the array
    *is* the waveform.
  </Step>
  <Step check={{ fn: "(h) => h.every((e) => e.value.partials && e.value.partials.length === 8 && e.value.partials[1] === 0 && e.value.partials[2] === 0.3) || 'Expected eight partials, the second 0 and the third 0.3.'" }}
        hints={['Zero out the even entries and give the odd ones falling amplitudes.']}
        solution={`note("c2 g2 c3 g2")
  .s("user")
  .partials(
    [1, 0, 0.3, 0, 0.1, 0, 0, 0.3]
  )`}>
    Change the array to `[1, 0, 0.3, 0, 0.1, 0, 0, 0.3]`. Mostly odd harmonics, plus a loud eighth:
    hollow with a glassy ring on top.
  </Step>
  <Step check={{ includes: 'new Array(', fn: "(h) => h.every((e) => e.value.partials && e.value.partials.length === 16) || 'Expected a computed array of 16 partials.'" }}
        hints={['It is plain JavaScript inside the call: build the array, then `.map` it.']}
        solution={`note("c2 g2 c3 g2")
  .s("user")
  .partials(
    new Array(16).fill(0).map((_, i) => ((-1) ** (i + 1)) / (i + 1))
  )`}>
    Compute them instead. Replace the array with
    `new Array(16).fill(0).map((_, i) => ((-1) ** (i + 1)) / (i + 1))`. Every harmonic at `1/n`
    with alternating signs is the Fourier series of a sawtooth: you have just rebuilt one by hand.
  </Step>
  <Step check={{ includes: '.phases(', fn: "(h) => h.every((e) => Array.isArray(e.value.phases) && e.value.phases.length === 16) || 'Expected a phases array of 16 entries.'" }}
        hints={['`randL(n)` is a list of n random numbers.']}
        solution={`note("c2 g2 c3 g2")
  .s("user")
  .partials(
    new Array(16).fill(0).map((_, i) => ((-1) ** (i + 1)) / (i + 1))
  )
  .phases(randL(16))`}>
    Add `.phases(randL(16))`. The spectrum is unchanged — the same harmonics at the same
    amplitudes — but the waveform looks and feels different. Re-evaluate a few times: each one is
    a new random set.
  </Step>
</Exercise>

Entries can be patterns as well as numbers: `partials([1, 1, "<1 0>", "<1 0>"])` switches the upper
harmonics on and off every bar. And `randL(200)` in both `partials` and `phases` is a cheap way to
generate a waveform nobody has heard before.

<Exercise id="synths/partials-challenge" title="Challenge: odd harmonics only"
  goal="`c3 e3 g3 e3` on the `user` source, built from harmonics 1, 3, 5 and 7 at full strength and nothing else."
  start={`note("c3 e3 g3 e3").s("user")`}
  target={`note("c3 e3 g3 e3").s("user").partials([1, 0, 1, 0, 1, 0, 1])`}
  check={{ events: 4, has: { s: 'user' }, fn: "(h) => h.every((e) => { const p = e.value.partials; return Array.isArray(p) && p.length >= 7 && p[0] > 0 && p[2] > 0 && p[4] > 0 && p[6] > 0 && !p[1] && !p[3] && !p[5]; }) || 'Expected the odd harmonics on and the even ones at 0.'" }}
  hints={[
    'The first entry of the array is the fundamental, the second is the octave above it.',

  ]} />

## Wavetables

Any sample whose name starts with `wt_` is treated as a **wavetable**: a file of single-cycle
waveforms, looped at your note's frequency instead of played back. `n` picks which waveform in the
file, and sweeping `n` is the whole point — it is the wavetable-position knob from Serum or the
Wavetable device in Live. Over a thousand from the AKWF set are available.

<Exercise id="synths/wavetables" title="Scan a wavetable"
  goal="Play a bass line through a wavetable and sweep across the table while it runs."
  start={`samples('github:bubobubobubobubo/dough-waveforms')
note("c2*8")
  .s("sawtooth")`}
  target={`samples('github:bubobubobubobubo/dough-waveforms')
note("c2*8")
  .s("wt_dbass")
  .n(saw.range(0, 8).slow(4))`}>
  <Step check={{ has: { s: 'wt_dbass' } }}
        hints={['The `samples(...)` line on top is what makes the `wt_*` names available.']}
        solution={`samples('github:bubobubobubobubo/dough-waveforms')
note("c2*8")
  .s("wt_dbass")`}>
    Change `sawtooth` to `wt_dbass`. The first bar may be silent while the file downloads — sounds
    load lazily, so the first hit of anything new can be missing.
  </Step>
  <Step check={{ includes: '.n(', has: { n: 3 } }}
        hints={['`n` here is an index into the file, exactly like picking a sample from a folder.']}
        solution={`samples('github:bubobubobubobubo/dough-waveforms')
note("c2*8")
  .s("wt_dbass")
  .n(3)`}>
    Add `.n(3)`: a different single-cycle waveform out of the same file. Try `0`, `3` and `7` and
    listen to how far apart they are.
  </Step>
  <Step check={{ includes: 'run(', match: { keys: ['n'] } }}
        target={`samples('github:bubobubobubobubo/dough-waveforms')
note("c2*8")
  .s("wt_dbass")
  .n(run(8))`}
        solution={`samples('github:bubobubobubobubo/dough-waveforms')
note("c2*8")
  .s("wt_dbass")
  .n(run(8))`}>
    Change it to `.n(run(8))`: a different waveform on every eighth note. One note, eight timbres.
  </Step>
  <Step check={{ includes: 'saw.range(', cycles: 4, match: { keys: ['n'] } }}
        hints={['`saw` is a signal that ramps from 0 to 1 every cycle; `.range(a, b)` rescales it.']}
        solution={`samples('github:bubobubobubobubo/dough-waveforms')
note("c2*8")
  .s("wt_dbass")
  .n(saw.range(0, 8).slow(4))`}>
    Now automate it properly: `.n(saw.range(0, 8).slow(4))`. One slow sweep across the whole table
    every four bars, sampled at each note — the knob is now moving by itself.
  </Step>
</Exercise>

A wavetable is only a looped fragment of audio, so you can make one out of anything: loop a short
enough piece of any sample and the loop rate lands in the audio range, which your ear reads as
pitch rather than rhythm.

<Exercise id="synths/loop-oscillator" title="Turn a kick into an oscillator"
  goal="Loop the first few percent of a bass drum until it stops being a drum and becomes a note."
  start={`note("c3")
  .s("bd")
  .gain(.2)`}
  target={`note("<c3 eb3 g3 f3>")
  .s("bd")
  .gain(.2)
  .loop(1)
  .loopEnd(.05)`}>
  <Step check={{ includes: 'note("<c3', cycles: 4, match: { keys: ['note', 's'] } }}
        target={`note("<c3 eb3 g3 f3>")
  .s("bd")
  .gain(.2)`}
        hints={['`note` sets the playback pitch of a sample, one per bar here.']}
        solution={`note("<c3 eb3 g3 f3>")
  .s("bd")
  .gain(.2)`}>
    One kick per bar. The `.gain(.2)` is there already because what comes next gets loud. Change
    `note("c3")` to `note("<c3 eb3 g3 f3>")`: one kick per bar, transposed, still unmistakably a
    kick.
  </Step>
  <Step check={{ includes: '.loop(', has: { loop: 1 } }}
        solution={`note("<c3 eb3 g3 f3>")
  .s("bd")
  .gain(.2)
  .loop(1)`}>
    Add `.loop(1)`. The file now repeats for as long as the event lasts instead of playing once.
  </Step>
  <Step check={{ includes: '.loopEnd(', has: { loopEnd: [0.3, 0.8] } }}
        hints={['`loopEnd` is a fraction of the file, so `.5` is its first half.']}
        solution={`note("<c3 eb3 g3 f3>")
  .s("bd")
  .gain(.2)
  .loop(1)
  .loopEnd(.5)`}>
    Add `.loopEnd(.5)`: only the first half of the file loops. You can still count the repeats —
    it is a very fast rhythm.
  </Step>
  <Step check={{ has: { loopEnd: [0.005, 0.1] }, cycles: 4, match: { keys: ['note', 's', 'loop', 'loopEnd', 'gain'] } }}
        hints={['Ten times shorter than the last one.']}
        solution={`note("<c3 eb3 g3 f3>")

  .gain(.2)
  .loop(1)
  .loopEnd(.05)`}>
    Change it to `.loopEnd(.05)`. Counting the repeats is now impossible: the loop rate has crossed
    into the audio range and your ear hears a pitch that follows the `note`. That is a wavetable,
    hand-made — and the same threshold as `hh*32` in
    <L to="/tutorial/mini-notation">Mini-Notation</L>.
  </Step>
</Exercise>

## ZZFX

The "Zuper Zmall Zound Zynth" is a second engine bolted on for game sound effects, with its own
parameter set. Its sounds are prefixed `z_`.

<Exercise id="synths/zzfx" title="The other engine"
  goal="Play one bass line through the ZZFX oscillators and bend it with two ZZFX-only controls."
  start={`note("c2 eb2 f2 g2").s("sawtooth")`}
  target={`note("c2 eb2 f2 g2").s("{z_sawtooth z_tan z_noise z_sine z_square}%4").zcrush(.4).pitchJump(12).pitchJumpTime(.05)`}>
  <Step check={{ has: { s: 'z_sawtooth' } }}
        solution={`note("c2 eb2 f2 g2").s("z_sawtooth")`}>
    Change `sawtooth` to `z_sawtooth`. Same waveform on paper, rougher in practice: this is a
    different synthesis engine with its own envelope defaults.
  </Step>
  <Step check={{ includes: '%4', cycles: 5, match: { keys: ['s'] } }}
        target={`note("c2 eb2 f2 g2").s("{z_sawtooth z_tan z_noise z_sine z_square}%4")`}
        hints={['Five sounds, four steps per cycle: a polymeter, so the pairing rotates.']}
        solution={`note("c2 eb2 f2 g2").s("{z_sawtooth z_tan z_noise z_sine z_square}%4")`}>
    Change the sound to `"{z_sawtooth z_tan z_noise z_sine z_square}%4"`. Five sources over four
    steps, so the combination only comes round every five bars.
  </Step>
  <Step check={{ includes: '.zcrush(', has: { zcrush: [0.1, 1] } }}
        hints={['`zcrush` runs from 0 to 1.']}
        solution={`note("c2 eb2 f2 g2").s("{z_sawtooth z_tan z_noise z_sine z_square}%4").zcrush(.4)`}>
    Add `.zcrush(.4)`: bit crushing, built into the engine. Straight to 8-bit.
  </Step>
  <Step check={{ includes: '.pitchJump(', has: { pitchJump: [1, 24] } }}
        solution={`note("c2 eb2 f2 g2").s("{z_sawtooth z_tan z_noise z_sine z_square}%4").zcrush(.4).pitchJump(12)`}>
    Add `.pitchJump(12)`. Nothing audible yet — it says *how far* the pitch jumps mid-note, not
    when.
  </Step>
  <Step check={{ has: { pitchJumpTime: [0.01, 0.5] }, cycles: 5, match: { keys: ['s', 'note', 'zcrush', 'pitchJump', 'pitchJumpTime'] } }}
        hints={['The companion control ends in `Time` and takes seconds.']}
        solution={`note("c2 eb2 f2 g2").s("{z_sawtooth z_tan z_noise z_sine z_square}%4").zcrush(.4).pitchJump(12).pitchJumpTime(.05)`}>

  </Step>
</Exercise>

The rest of the ZZFX parameters follow the same shape: `zrand`, `curve` (waveshape, 1–3), `slide`
and `deltaSlide` for pitch slides, `noise`, `zmod` (FM speed), `zdelay` and `tremolo`. ZZFX's own
LFO is not exposed, because it collides with the modulator LFO in
<L to="/tutorial/lfo">LFOs</L>.

## Building an instrument from nothing

<QA q="How do I make a kick drum from scratch?">
A sine with a fast, deep, exponential pitch envelope and a short amplitude decay. The whole trick is
that a kick is a *pitch envelope*, not a waveform: it starts up near 100 Hz and falls to the
fundamental within a few dozen milliseconds. Add `.distort("2:.4")` for weight. The envelope
controls themselves live in <L to="/tutorial/envelopes">Envelopes</L>.
</QA>

<Exercise id="synths/kick-challenge" title="Challenge: a kick from a sine"
  goal="`g1` four to the floor on a sine: pitch envelope 32 semitones, curve 1, pitch decay .08, amplitude decay .2, sustain 0."
  start={`note("g1*4").s("sine")`}
  target={`note("g1*4").s("sine").penv(32).pcurve(1).pdec(.08).decay(.2).sustain(0)`}
  check={{ events: 4, has: { s: 'sine', penv: [16, 48], pdec: [0.02, 0.2], decay: [0.05, 0.4], sustain: 0 } }}
  hints={[
    'Pitch envelope controls start with `p`: depth, curve, and how fast it falls.',
    'Amplitude decay and sustain are the ordinary ADSR controls — sustain 0 means the note never holds.',
    'Set the pitch depth first and listen to it alone; the rest is shaping.',
  ]} />

## Recap

| Control | Purpose |
| --- | --- |
| `s("sine/tri/square/saw")` | basic oscillators (default: `triangle`) |
| `s("supersaw")` + `unison` `detune` `spread` | fat stacked saws |
| `s("pulse")` + `pw` `pwrate` `pwsweep` | pulse width modulation |
| `s("white/pink/brown")`, `noise`, `crackle` + `density` | noise sources |
| `vib` `vibmod`, or `vib("rate:depth")` | vibrato |
| `fm` `fmh` `fmattack` `fmdecay` `fmsustain` `fmenv` | FM synthesis |
| `partials` `phases` | additive synthesis |
| `wt_*` samples + `n` | wavetable synthesis |
| `loop` + `loopEnd` | any sample as an oscillator |
| `z_*` sounds | the ZZFX engine |
