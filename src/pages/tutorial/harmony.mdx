## Chord symbols

`chord()` takes a pattern of symbols: a capital root with an optional `b` or `#`, then a quality.
`voicing()` looks the quality up in a dictionary, and a quality it does not know is **silence**.

  goal="Break a chord by spelling it the lead-sheet way, fix it, then colour the other three."

    Play it once, then change `C^7` to `Cmaj7`. The first bar goes silent, and nothing in the
    editor tells you why: `maj7` is not in the dictionary, so that chord produces no notes.
  </Step>
  <Step check={{ excludes: 'maj7', match: { keys: ['note', 's'] }, cycles: 4 }}
        target={`chord("<CM7 A7 Dm7 G7>").voicing().s("piano")`}
        hints={['`^7` and `M7` both mean major seventh.']}
        solution={`chord("<CM7 A7 Dm7 G7>").voicing().s("piano")`}>
    Change `Cmaj7` to `CM7`. The bar is back, with exactly the notes `C^7` gave: `M7` and `^7`
    are the same entry.
  </Step>
  <Step check={{ includes: 'A7b9', match: { keys: ['note', 's'] }, cycles: 4 }}
        target={`chord("<CM7 A7b9 Dm7 G7>").voicing().s("piano")`}
        hints={['Alterations go straight after the `7`, no brackets.']}
        solution={`chord("<CM7 A7b9 Dm7 G7>").voicing().s("piano")`}>
    Change `A7` to `A7b9`. The voicing now has a B flat in it, and the A7 pulls much harder
    towards the Dm7.
  </Step>
  <Step check={{ includes: 'Dm9', match: { keys: ['note', 's'] }, cycles: 4 }}
        target={`chord("<CM7 A7b9 Dm9 G7>").voicing().s("piano")`}
        hints={['Ninths are written like sevenths, with a 9.']}
        solution={`chord("<CM7 A7b9 Dm9 G7>").voicing().s("piano")`}>
    Change `Dm7` to `Dm9`. Listen for the E4 sitting right next to the F4: a semitone cluster in
    the middle of the chord.
  </Step>
  <Step check={{ includes: 'G7alt', match: { keys: ['note', 's'] }, cycles: 4 }}
        hints={['The altered dominant is one word after the `7`.']}
        solution={`chord("<CM7 A7b9 Dm9 G7alt>").voicing().s("piano")`}>
    Change `G7` to `G7alt`. This voicing has B and F (the tritone), plus D flat and B flat: the
    flat five and the sharp nine. It resolves back to the CM7 at the top of the loop.
  </Step>

What the default dictionary (`ireal`) knows, checked one symbol at a time:

| Kind | Symbols that work (on C) |
| --- | --- |
| triads | `C` `CM` `C^` · `Cm` `C-` · `Co` · `Caug` · `Csus` · `C5` |
| sixths, added notes | `C6` `Cm6` `C69` `Cm69` `Cadd9` `C2` |
| sevenths | `C^7` = `CM7` · `C7` · `Cm7` = `C-7` · `Ch7` = `Cm7b5` · `Co7` · `Cm^7` · `C7sus` |
| extensions | `C9` `C^9` `Cm9` `C11` `Cm11` `C13` `C9sus` |
| altered dominants | `C7b9` `C7#9` `C7#11` `C7b13` `C7b5` `C7#5` `C7alt` `C13b9` `C9#11` `C7b9sus` |
| roots | any of `C D E F G A B`, with `b` or `#`: `Bb7`, `F#m7`, `Ebm7`, `Db^7` |

<Box kind="warn">
These are **silent**, not errors: `Cmaj7`, `Cmin7`, `Cdim`, `Cdim7`, `CmM7`, and a lowercase root
like `c7`. These are **errors**, because mini-notation reserves the character: `C+` and slash
chords like `C/E` (`/` means "slow down"). There is no slash-chord syntax; put the bass note in its
own lane, as in the section on bass below.
</Box>

## chord() or a bare string

The notes chapter wrote both `"<C^7 Am7>".voicing()` and `chord("<C^7 Am7>").voicing()`. They are
not the same thing, and the difference only shows once you add a control.

<Exercise id="harmony/bare-string" title="The lane that went silent"
  goal="Reproduce the silent-voicing trap, fix it, and then fix the bass lane the same way."
  start={`$: "<Dm7 G7 C^7>".voicing().s("piano")
$: "<Dm7 G7 C^7>".rootNotes(2).note().s("gm_acoustic_bass")`}
  target={`$: chord("<Dm7 G7 C^7>").dict('lefthand').voicing().s("piano")
$: chord("<Dm7 G7 C^7>").rootNotes(2).s("gm_acoustic_bass")`}>
  <Step check={{ includes: 'lefthand', events: 3, cycles: 3 }}
        hints={['It goes on the first line only, between the string and `.voicing()`.']}
        solution={`$: "<Dm7 G7 C^7>".dict('lefthand').voicing().s("piano")
$: "<Dm7 G7 C^7>".rootNotes(2).note().s("gm_acoustic_bass")`}>
    In the first lane, add `.dict('lefthand')` before `.voicing()`. The piano disappears and the
    bass carries on. No error: the piano lane simply has zero notes in it now.
  </Step>
  <Step check={{ includes: 'chord(', match: { keys: ['note', 's'] }, cycles: 3 }}
        target={`$: chord("<Dm7 G7 C^7>").dict('lefthand').voicing().s("piano")
$: "<Dm7 G7 C^7>".rootNotes(2).note().s("gm_acoustic_bass")`}
        hints={['The string moves inside `chord(...)`; nothing else on the line changes.']}
        solution={`$: chord("<Dm7 G7 C^7>").dict('lefthand').voicing().s("piano")
$: "<Dm7 G7 C^7>".rootNotes(2).note().s("gm_acoustic_bass")`}>
    Wrap the first lane's string in `chord(...)`: `chord("<Dm7 G7 C^7>").dict('lefthand')`. The
    piano is back, now playing four-note left-hand voicings.
  </Step>
  <Step check={{ code: 'chord\\([^)]*\\)\\s*\\.rootNotes', excludes: '.note()', match: { keys: ['note', 's'] }, cycles: 3 }}
        hints={['Two edits on the second line: the string goes inside `chord(...)`, and `.note()` goes away.',
                '`rootNotes` hands back the same kind of thing it was given.']}
        solution={`$: chord("<Dm7 G7 C^7>").dict('lefthand').voicing().s("piano")
$: chord("<Dm7 G7 C^7>").rootNotes(2).s("gm_acoustic_bass")`}>
    Do the same to the bass lane, and delete its `.note()`:
    `chord("<Dm7 G7 C^7>").rootNotes(2).s("gm_acoustic_bass")`. It sounds the same. From a bare
    string, `rootNotes` returns a bare note name that still needs `.note()`; from `chord()`, it
    already returns a note, and a second `.note()` would wrap it twice and lose the pitch.
  </Step>
</Exercise>

<Box>
**The rule.** A bare string that reaches `voicing()` untouched is read as the chord. Chain
anything onto it first (`dict`, `anchor`, `mode`, `offset`, even `s`) and the event becomes a set
of controls: the string is dropped, and `voicing()` receives no chord at all. `chord()` makes the
symbol a control like the others, so it survives. **As soon as there is one control before
`voicing()`, start with `chord()`.** And `rootNotes` after `chord()` needs no `.note()`.
</Box>

## Why that inversion

`voicing()` does not remember the previous chord. For each chord it tries every shape the
dictionary has and keeps the one whose **top note** lands closest to a reference note, the
**anchor**, without going over it. The default anchor is `c5`. Every chord hugs the same ceiling,
so the top voice barely moves: the smooth voice leading comes from that, not from looking back.

<Exercise id="harmony/anchor" title="Move the ceiling"
  goal="Make the default anchor explicit, lower it, then anchor the bottom of the chord instead of the top."
  start={`chord("<Dm7 G7 C^7 A7>").dict('lefthand').voicing().s("piano")`}
  target={`chord("<Dm7 G7 C^7 A7>").dict('lefthand').anchor("f4").mode("above").voicing().s("piano")`}>
  <Step check={{ includes: 'anchor(', match: { keys: ['note', 's'] }, cycles: 4 }}
        target={`chord("<Dm7 G7 C^7 A7>").dict('lefthand').voicing().s("piano")`}
        hints={['It is a control, so it goes before `.voicing()`.']}
        solution={`chord("<Dm7 G7 C^7 A7>").dict('lefthand').anchor("c5").voicing().s("piano")`}>
    Add `.anchor("c5")` before `.voicing()`. Nothing changes, because that is the default. The
    top notes are A4, A4, G4, B4: all at or just under c5.
  </Step>
  <Step check={{ includes: 'f4', match: { keys: ['note', 's'] }, cycles: 4 }}
        target={`chord("<Dm7 G7 C^7 A7>").dict('lefthand').anchor("f4").voicing().s("piano")`}
        hints={['Only the note name inside `anchor` changes.']}
        solution={`chord("<Dm7 G7 C^7 A7>").dict('lefthand').anchor("f4").voicing().s("piano")`}>
    Change it to `anchor("f4")`. The tops are now E4, E4, D4, B3, and it is not a transposition:
    Dm7, G7 and CM7 switch to their other shape to stay under the new ceiling. The A7 keeps its
    shape and drops a whole octave, because its other top note, F♯4, is a semitone over f4.
  </Step>
  <Step check={{ includes: 'mode(', match: { keys: ['note', 's'] }, cycles: 4 }}
        hints={['`mode` is a second control, next to `anchor`.']}
        solution={`chord("<Dm7 G7 C^7 A7>").dict('lefthand').anchor("f4").mode("above").voicing().s("piano")`}>
    Add `.mode("above")` next to the anchor. Now the **bottom** note is what gets anchored: F4,
    F4, E4, D♭4, each at or just under f4, and the chord stacks upward from there. The comp jumps
    up and spreads above the anchor instead of hanging below it.
  </Step>
</Exercise>

| `mode` | What lands on the anchor (or just under it) |
| --- | --- |
| `below` (default) | the top note |
| `above` | the bottom note, with the chord stacked above it |
| `duck` | like `below`, but if the top note *is* the anchor, it is removed |
| `root` | the dictionary's first shape, bottom note at or under the anchor |

`mode` also takes the anchor after a colon: `mode("above:f4")` is the same as
`.anchor("f4").mode("above")`.

<Exercise id="harmony/anchor-challenge" title="Challenge: write the top voice"

## Inversions on demand

A left-hand dictionary has exactly two shapes per chord: one with the **third** on the bottom and
one with the **seventh** on the bottom. Through a ii–V–I they alternate, which is why the inner
voices move by step: Dm7 C–E–F–A, G7 B–E–F–A, CM7 B–D–E–G. No voice moves more than a whole tone.
`offset` walks through the shapes.

<Exercise id="harmony/offset" title="Walk the inversions"
  goal="Step the same progression up and down through its shapes."
  start={`chord("<Dm7 G7 C^7>").dict('lefthand').voicing().s("piano")`}
  target={`chord("<Dm7 G7 C^7>").dict('lefthand').offset(-1).voicing().s("piano")`}>
  <Step check={{ includes: 'offset(', match: { keys: ['note', 's'] }, cycles: 3 }}
        target={`chord("<Dm7 G7 C^7>").dict('lefthand').offset(1).voicing().s("piano")`}
        hints={['Another control, before `.voicing()`, with a whole number.']}
        solution={`chord("<Dm7 G7 C^7>").dict('lefthand').offset(1).voicing().s("piano")`}>
    Add `.offset(1)`. Every chord moves to its other shape, one inversion up: Dm7 is now F–A–C–E
    (third on the bottom), G7 is F–A–B–E (seventh on the bottom). Still alternating, just the other
    way round.
  </Step>
  <Step check={{ includes: 'offset(2)', match: { keys: ['note', 's'] }, cycles: 3 }}
        target={`chord("<Dm7 G7 C^7>").dict('lefthand').offset(2).voicing().s("piano")`}
        hints={['Only the number changes.']}
        solution={`chord("<Dm7 G7 C^7>").dict('lefthand').offset(2).voicing().s("piano")`}>
    Make it `offset(2)`. With two shapes, two steps up is the original shape an octave higher.
  </Step>
  <Step check={{ includes: 'offset(-1)', match: { keys: ['note', 's'] }, cycles: 3 }}
        hints={['Negative numbers go down.']}
        solution={`chord("<Dm7 G7 C^7>").dict('lefthand').offset(-1).voicing().s("piano")`}>
    Make it `offset(-1)`: one shape below the default, down around middle C where a pianist's left
    hand actually lives.
  </Step>
</Exercise>

`duck` and `root` answer two other questions: how to keep a melody note out of the chord, and how
to put the root in the bass.

<Exercise id="harmony/duck-root" title="Duck the top, find the root"
  goal="Remove the anchor note from the voicing, then switch to root-position voicings with the root in the bass."

  target={`chord("<Dm7 G7 C^7>").anchor("c3").mode("root").voicing().s("piano")`}>
  <Step check={{ includes: 'duck', events: 10, cycles: 3 }}
        hints={['`mode` goes next to `anchor`.']}
        solution={`chord("<Dm7 G7 C^7>").dict('lefthand').anchor("a4").mode("duck").voicing().s("piano")`}>
    Add `.mode("duck")`. The A4 on top of Dm7 and G7 is gone, and they play three notes; CM7 had no
    A on top, so it keeps all four. This is how you voice under a melody: the melody note is the
    anchor, and the chord leaves it to the melody.
  </Step>
  <Step check={{ excludes: 'lefthand', match: { keys: ['note', 's'] }, cycles: 3 }}
        target={`chord("<Dm7 G7 C^7>").anchor("a4").mode("duck").voicing().s("piano")`}
        hints={['Delete the whole `.dict(...)` call.']}
        solution={`chord("<Dm7 G7 C^7>").anchor("a4").mode("duck").voicing().s("piano")`}>
    Delete `.dict('lefthand')`. Back to the default `ireal`: bigger voicings, four or five notes,
    spread down to B2, still under a4 and still without it.
  </Step>
  <Step check={{ includes: 'root', match: { keys: ['note', 's'] }, cycles: 3 }}
        target={`chord("<Dm7 G7 C^7>").anchor("a4").mode("root").voicing().s("piano")`}
        hints={['Only the word inside `mode` changes.']}
        solution={`chord("<Dm7 G7 C^7>").anchor("a4").mode("root").voicing().s("piano")`}>
    Change `"duck"` to `"root"`. Root position, with the root at or just under a4: D4, G4, C4. And
    everything else stacked above it, up to B5. Far too high.
  </Step>
  <Step check={{ includes: 'c3', match: { keys: ['note', 's'] }, cycles: 3 }}
        hints={['The root lands at or under the anchor, so move the anchor.']}
        solution={`chord("<Dm7 G7 C^7>").anchor("c3").mode("root").voicing().s("piano")`}>
    Change the anchor to `"c3"`. Roots D2, G2, C3: a two-handed voicing with a bass note. Listen to
    the Dm7: F2 and A2 a third apart that low turn to mud, which is why pianists hand the bass to
    someone else. That is the section after next.
  </Step>
</Exercise>

<Box>
`root` means "the dictionary's first shape", not "the root". In `ireal` the first shape is root
position for most qualities, but not half-diminished: `Bh7` in root mode puts D on the bottom. In
`lefthand` there is no root in any shape, so `root` just gives you the third-on-the-bottom shape.
</Box>

## Dictionaries

A dictionary is a set of answers to "what would a pianist play for this symbol?". Each one is
written for a different job, and each one only knows the qualities it lists.

    `.dict('lefthand')` to the piano. Four notes, all between B3 and A4, and **no root**: the
    Dm7 has no D in it. That is the bassist's note.
  </Step>
  <Step check={{ includes: 'guidetones', events: 12, cycles: 4 }}

  </Step>

    Change the piano's symbols to plain triads: `"<Dm G C C>"`. The piano goes silent. A triad has
    no seventh, so `guidetones` has nothing to say about it, and `lefthand` would be silent too.
  </Step>
  <Step check={{ includes: 'triads', events: 16, cycles: 4 }}
        hints={['A dictionary named after what it knows.']}
        solution={`$: chord("<Dm G C C>").dict('triads').voicing().s("piano")
$: chord("<Dm7 G7 C^7 C^7>").rootNotes(2).s("gm_acoustic_bass")`}>
    Change the dictionary to `'triads'`. Close-position triads, D–F–A, D–G–B, E–G–C: each in
    whichever inversion puts its top note closest to c5 without going over.
  </Step>
  <Step check={{ includes: 'legacy', events: 16, cycles: 4 }}
        hints={['Only the dictionary name changes.']}
        solution={`$: chord("<Dm G C C>").dict('legacy').voicing().s("piano")
$: chord("<Dm7 G7 C^7 C^7>").rootNotes(2).s("gm_acoustic_bass")`}>
    Change it to `'legacy'`. Identical: `legacy` is the old default, and its triads are these ones.
  </Step>
  <Step check={{ includes: 'legacy', match: { keys: ['note', 's'] }, cycles: 4 }}
        hints={['Put the sevenths back into the piano line: the same symbols as the bass line.']}
        solution={`$: chord("<Dm7 G7 C^7 C^7>").dict('legacy').voicing().s("piano")
$: chord("<Dm7 G7 C^7 C^7>").rootNotes(2).s("gm_acoustic_bass")`}>
    Put the sevenths back: `"<Dm7 G7 C^7 C^7>"`. Not silent this time, and you have heard these
    voicings before: `legacy`'s sevenths are the `lefthand` shapes. It is the one dictionary that
    covers both triads and sevenths with small voicings.
  </Step>

| Dictionary | Notes | Knows | Use it for |
| --- | --- | --- | --- |
| `ireal` (default) | 4–5, two hands | over 60 qualities, triads to `7alt` | a full piano sound on its own |
| `ireal-ext` | 5 | the same symbols; some shapes add extensions (its CM7 adds the 9th and 13th) | a lusher version of the same |
| `lefthand` | 4, rootless (except `o7`) | sevenths and a few sixths and altered chords, **no triads** | comping over a bass |
| `guidetones` | 2: third and seventh | sevenths and sixths, **no triads** | the sparest comp, or a second instrument |
| `triads` | 3 | `''` `M` `m` `o` `aug` only | pop and rock |
| `legacy` | 3 or 4 | triads plus the `lefthand` sevenths | mixing both |

## Your own dictionary

`addVoicings(name, dictionary)` registers a new one. The dictionary is an object from quality to a
list of shapes, and each shape is a string of intervals above the root: names like `1P 3m 7m`, or
semitones like `0 3 10`. `voicing()` tries every shape and anchors it exactly as before.

<Exercise id="harmony/add-voicings" title="Bud Powell shells"
  goal="Build a dictionary of three-note shells, root plus third plus seventh, for a low left hand."

## A bass that agrees

A comp and a bass read from the **same** chord pattern cannot disagree. Name the pattern once and
give each player its own lane.

## Comping

A chord held for the whole bar is a pad. A pianist comping plays short chords in a rhythm, leaves
space for the soloist, and often plays the next bar's chord early.

<QA q="Does voicing() lead each voice from the previous chord?">
No. It is stateless: every chord is voiced on its own, against the anchor. The smooth motion is a
consequence of every chord sharing the same ceiling, and of the `lefthand` shapes being written so
that the two forms alternate. If a change leaps, move the ceiling (`anchor`) or pick the other
shape (`offset`) for that one chord. The deprecated `voicings()`, with an s, did remember the last
chord; do not use it.
</QA>

<QA q="Why does F#m7 come out as Gb, Db and so on?">
`voicing()` names every note with flats. The pitches are right. It only matters if you read the
note names in the pattern display.
</QA>

## Recap

| Function | Purpose |
| --- | --- |
| `chord("<Dm7 G7>")` | chord symbols as a control; required once any other control is chained |
| `voicing()` | symbols to notes: the shape whose top note is closest under the anchor |
| `dict('lefthand')` | `ireal` (default), `ireal-ext`, `lefthand`, `guidetones`, `triads`, `legacy` |
| `anchor("f4")` | the reference note; the default is `c5` |
| `mode("below")` | which note lands on the anchor: `below`, `above`, `duck`, `root` |
| `offset(1)` | the next shape up; `-1` the next one down |
| `rootNotes(2)` | the root in octave 2; no `.note()` after `chord()`, `.note()` after a bare string |
| `addVoicings('name', { m7: ['…'] })` | your own dictionary; single quotes inside |
| `struct("x ~ ~ x ~ ~ ~ ~")` | a comping rhythm |
| `early(1/8)` on the chords | push the changes an eighth ahead of the barline |
