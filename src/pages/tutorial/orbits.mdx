Everything in this chapter follows from one picture: what happens to a sound between the pattern
and your speakers. Read the list once, then spend the rest of the chapter proving it by typing.

## The signal chain

1. **A sound is triggered** by an event, with a start time and duration.
2. **The source is produced** — a sample plays, or an oscillator runs. Detune-type effects
   (`detune`, `penv`, vibrato) happen here.
3. **The local effect chain** runs, in this fixed order:
   `stretch` → `gain` (and the amplitude ADSR) → `lpf` → `hpf` → `bandpass` → `vowel` →
   `coarse` → `crush` → `shape` → `distort` → `tremolo` → `compressor` → `pan` → `phaser` →
   `postgain`
4. **The signal splits** into:
   - the **dry** output (level set by `dry`)
   - the **delay** send (level set by `delay`)
   - the **reverb** send (level set by `room`)
   - analysers for `scope` / `spectrum`
5. Dry, delay and reverb are summed into **the orbit**.
6. `duck` modulates the volume of everything in the orbit.
7. The orbit goes to the mixer and out.

<Box>
Steps 1–4 happen **per event**. Steps 5–7 happen **per orbit**. That is the entire distinction
between a local and a global effect.
</Box>

## Local effects are single-use

Each local effect appears exactly once in that chain. Write it twice and the second value simply
replaces the first. The next exercise makes that audible.

<Exercise id="orbits/single-use" title="Two filters, one filter"
  goal="Prove that a second `.lpf()` does not filter again — it overwrites the first one."
  start={`s("bd*4, hh*8")`}
  target={`s("bd*4, hh*8").distort(2).lpf(2000)`}>
  <Step check={{ includes: '.lpf(', has: { lpf: [100, 400] }, events: 12 }}
        hints={['`lpf` is the lowpass cutoff in Hz; 200 is very low, so almost all of the hats go.']}
        solution={`s("bd*4, hh*8").lpf(200)`}>
    Add `.lpf(200)` to the end. Muffled: the hats nearly vanish and the kick loses its click.
  </Step>
  <Step check={{ includes: '.distort(', has: { lpf: [100, 400], distort: [1, 4] } }}
        solution={`s("bd*4, hh*8").lpf(200).distort(2)`}>
    Add `.distort(2)` after it. Dirty, but still dark — the distortion is running on the filtered
    signal, which is what the chain order says.
  </Step>
  <Step check={{ has: { lpf: [1200, 4000] },
                 fn: "(h, code) => (code.match(/\\.lpf\\(/g) || []).length === 2 || 'Keep both `.lpf()` calls: the old one and the new one.'" }}
        hints={['Distortion adds a lot of fizz up top, so a filter after it is a normal thing to want.',
                'Leave the first `.lpf(200)` exactly where it is and add the new one on the end.']}
        solution={`s("bd*4, hh*8").lpf(200).distort(2).lpf(2000)`}>
    Now try to tame the fizz: add a second `.lpf(2000)` at the very end. Listen carefully — it did
    not get darker, it got **brighter than step 1 ever was**. The `lpf(200)` is gone.
  </Step>
  <Step check={{ excludes: 'lpf(200)', has: { lpf: [1200, 4000], distort: [1, 4] },
                 fn: "(h, code) => (code.match(/\\.lpf\\(/g) || []).length === 1 || 'Exactly one `.lpf()` should be left.'" }}
        solution={`s("bd*4, hh*8").distort(2).lpf(2000)`}>
    Delete `.lpf(200)`. Identical. It was never doing anything — there is one lowpass slot per
    event and `2000` had already taken it.
  </Step>
</Exercise>

<Box kind="warn">
So `s("bd").lpf(100).distort(2).lpf(800)` does **not** lowpass, distort, then lowpass again. It
only applies `lpf(800)`. If you genuinely need the same effect twice, you need `FX()`, at the end
of this chapter.
</Box>

## One delay and one reverb per orbit

Delay and reverb are **not** local. They live on the orbit, so every pattern on that orbit shares
one delay and one reverb — and one set of knobs.

## Allocating orbits

Orbits are buses, so use them the way you use buses in a DAW — one per *space*, not one per sound.

| Orbit | Typical use |
| --- | --- |
| 1 | drums — dry, or a very short room |
| 2 | bass |
| 3 | leads / pads — the big reverb lives here |
| 4 | a dedicated delay throw |

## Sending one sound to several orbits

Mini-notation works in `orbit` too, so one sound can go to more than one bus. It is not a send: it
makes a **copy** per orbit.

<Exercise id="orbits/several" title="Copies, not sends"
  goal="Send one noise hit to three orbits and hear it get three times as loud."
  start={`s("white").gain(.6)`}
  target={`s("white").orbit("2,3,4").gain(.2)`}>
  <Step check={{ has: { orbit: 2 }, events: 1 }}
        solution={`s("white").orbit(2).gain(.6)`}>
    Add `.orbit(2)`. One hit, one bus, same level as before.
  </Step>
  <Step check={{ includes: 'orbit("2,3")', events: 2 }}
        hints={['A comma inside the quotes is the parallel operator — here it stacks two orbit values.']}
        solution={`s("white").orbit("2,3").gain(.6)`}>
    Change it to `.orbit("2,3")`. One event became two, and since both buses reach the same
    speakers you just doubled the level.
  </Step>
  <Step check={{ events: 3, has: { orbit: [2, 4] } }}
        solution={`s("white").orbit("2,3,4").gain(.6)`}>
    Go to `.orbit("2,3,4")`. Three copies now, and it is getting genuinely loud.
  </Step>
  <Step check={{ events: 3, has: { gain: [0.15, 0.25] } }}
        solution={`s("white").orbit("2,3,4").gain(.2)`}>
    Compensate: change `.gain(.6)` to `.gain(.2)`. Back where you started, on three buses.
  </Step>
</Exercise>

The real use for this is ducking several buses with one trigger, in

an orbit list.
</Box>

## postgain and dry

`gain` sits near the **start** of the local chain, before the filters and the distortion.
`postgain` sits at the very **end**, after all of them. That difference is the whole point.

<Exercise id="orbits/postgain" title="Turn it down without cleaning it up"
  goal="Use `gain` and `postgain` on the same distorted kick and hear why they are not the same knob."
  start={`s("bd*4").distort(3)`}
  target={`s("bd*4").gain(2).distort(3).postgain(.3).room(.9).rsize(4).dry(0)`}>
  <Step check={{ has: { gain: [0.2, 0.4], distort: [2, 4] } }}
        solution={`s("bd*4").distort(3).gain(.3)`}>
    Too loud. Add `.gain(.3)`. It is quieter — but also noticeably **cleaner**, because you turned
    the signal down *before* it hit the distortion.
  </Step>
  <Step check={{ excludes: '.gain(', has: { postgain: [0.2, 0.4] } }}
        hints={['`.postgain(` does not contain `.gain(` — delete the old call, do not just rename it in place.']}
        solution={`s("bd*4").distort(3).postgain(.3)`}>
    Delete `.gain(.3)` and write `.postgain(.3)` instead. Same level, all the dirt back: the
    distortion saw the full-strength signal and you turned down what came out.
  </Step>
  <Step check={{ has: { gain: [1.5, 3], postgain: [0.2, 0.4] } }}
        solution={`s("bd*4").gain(2).distort(3).postgain(.3)`}>
    Now use both. Add `.gain(2)` before the distortion and keep `.postgain(.3)`. Harder into the
    distortion, same level out — this is exactly how you drive a saturator in a DAW.
  </Step>
  <Step check={{ has: { room: [0.5, 1] } }}
        solution={`s("bd*4").gain(2).distort(3).postgain(.3).room(.9).rsize(4)`}>
    Add `.room(.9).rsize(4)`. The kick now leaves the event by two routes at once: straight out,
    and into the orbit's reverb.
  </Step>
  <Step check={{ includes: '.dry(', has: { dry: 0 } }}
        hints={['`dry` is the level of the untreated signal — step 4 of the chain at the top.']}
        solution={`s("bd*4").gain(2).distort(3).postgain(.3).room(.9).rsize(4).dry(0)`}>
    Add `.dry(0)`. The direct kick disappears and only the reverb of it is left. You just muted
    one of the three routes out of the event.
  </Step>
</Exercise>

## Your own chain, with FX()

`FX()` replaces the fixed order with one you write. It takes effects as arguments, applies them
left to right, and several `FX()` calls on one pattern **concatenate** into a single chain rather
than nesting.

<Exercise id="orbits/fx" title="Build the chain yourself"
  goal="Reorder a chain, then do the thing the fixed chain cannot: distort twice."
  start={`s("bd*4, hh*8").distort(2).lpf(700)`}
  target={`s("bd*4, hh*8").FX(lpf(700)).FX(distort(2), distort(1.5))`}>
  <Step check={{ includes: '.FX(', excludes: '.distort(',
                 fn: "(h) => { const k = h.filter(e => Array.isArray(e.value.FX) && e.value.FX.length === 2); return (h.length > 0 && k.length === h.length) || 'Every event should carry an `FX` chain of exactly two effects.'; }" }}
        hints={['Inside `FX()` the effects are written as plain calls, with no leading dot: `FX(distort(2), lpf(700))`.']}
        solution={`s("bd*4, hh*8").FX(distort(2), lpf(700))`}>
    Move both effects inside one call: `.FX(distort(2), lpf(700))`. It sounds the same as before —
    distortion first, then the filter — but now that order is yours, not the chain's.
  </Step>
  <Step check={{ fn: "(h) => { const f = h[0] && h[0].value.FX; return (f && f.length === 2 && f[0].cutoff !== undefined && f[1].distort !== undefined) || 'The chain should be `lpf` first, then `distort`.'; }" }}
        solution={`s("bd*4, hh*8").FX(lpf(700), distort(2))`}>
    Swap them: `.FX(lpf(700), distort(2))`. Same two effects, audibly different result — filtering
    first gives a round, fat drive; filtering last shaves the fizz off.
  </Step>
  <Step check={{ fn: "(h) => { const f = h[0] && h[0].value.FX; return (f && f.length === 3 && f[1].distort !== undefined && f[2].distort !== undefined) || 'Three effects, ending in two distortions in a row.'; }" }}
        hints={['Stacking two mild distortions is not the same as one hard one — the second one works on the first one’s harmonics.']}
        solution={`s("bd*4, hh*8").FX(lpf(700), distort(2), distort(1.5))`}>
    Add a second distortion at the end: `.FX(lpf(700), distort(2), distort(1.5))`. Two of the same
    effect in one chain, which the fixed order can never give you.
  </Step>
  <Step check={{ fn: "(h, code) => { const f = h[0] && h[0].value.FX; return ((code.match(/\\.FX\\(/g) || []).length === 2 && f && f.length === 3) || 'Two `.FX()` calls that still add up to three effects.'; }" }}
        hints={['Split after the filter, so the first call holds one effect and the second holds two.']}
        solution={`s("bd*4, hh*8").FX(lpf(700)).FX(distort(2), distort(1.5))`}>
    Split it into two calls: `.FX(lpf(700)).FX(distort(2), distort(1.5))`. Identical sound — chains
    concatenate, they do not nest, so you can build one up across several lines.
  </Step>
</Exercise>

## Multichannel output

By default every orbit is summed to channels 1 and 2. Turn on **Multi Channel Orbits** in the
official REPL's settings and orbit `i` maps to channels `2i-1` and `2i` instead — orbit 1 to
channels 1 and 2, orbit 2 to 3 and 4, and so on. Each orbit becomes a separate stereo output. With
a virtual audio device such as BlackHole 16, you can record every orbit as its own stem into a DAW.

`channels` and `pan` behave accordingly: in a multichannel setup, `pan` moves once around a circle
rather than between two speakers.

## The global controls

| Control | Meaning |
| --- | --- |
| `orbit(n)` / `o(n)` | which bus this event goes to |
| `dry(x)` | level of the untreated signal leaving the event |
| `postgain(x)` | gain applied after **all** local effects |
| `duckorbit(n)` | duck a different orbit — <L to="/tutorial/ducking">next chapter</L> |
| `channels` | explicit output channel routing |

<QA q="Is an orbit the same as a track?">
Not quite. A track is a *pattern* — one `$:` line. An orbit is a *bus* — a shared output with its
own delay, reverb and duck. Several tracks can share one orbit (and often should, so they sit in
the same space), and one track can be sent to several orbits.
</QA>

<QA q="Why did my reverb get shorter when I added a hi-hat line?">
Because the hat line set `roomsize` on the orbit they share, and the orbit has only one reverb.
Give the hats their own orbit, or leave `roomsize` off every lane but one.
</QA>

## Recap

| Idea | |
| --- | --- |
| Local effects | built per event, fixed order, single use |
| Global effects | one delay + one reverb **per orbit** |
| `orbit(n)` | choose the bus |
| Shared orbit | shared reverb/delay settings — last one wins |
| `orbit("2,3")` | send to several buses (duplicates the sound) |
| `dry(x)` | level of the untreated route out of the event |
| `postgain` | level after all local effects |
| `FX(...)` | build your own effect chain in your own order |
